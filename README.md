# Shanghai Octopus — Oriental Cuisine website

A responsive, image-led restaurant website concept for Shanghai Octopus in Independence Layout, Enugu.

## Features

- Luxury black, gold and deep-red visual direction.
- Mobile-first layout with responsive navigation.
- Food discovery sections, restaurant experience storytelling, venue/location details and contact information.
- Expanded **10-image swipe gallery** with touch scrolling, desktop drag, smooth snap scrolling, progress indicator and full-screen image viewer.
- Reservation/enquiry form that prepares a detailed WhatsApp message for the restaurant to confirm.
- Direct call, WhatsApp and Google Maps links.
- No fabricated customer reviews, sales figures or automated booking confirmations.

## Run locally

Open `index.html` in a modern browser. The Google Fonts and remote photographs require an internet connection.

## Important launch checklist

The gallery combines restaurant-setting photography with cuisine-led food imagery. Confirm menu details, prices, hours, address, phone and WhatsApp number with management. The reservation form opens WhatsApp; the restaurant must confirm each request. See `PITCH-GUIDE.md` for a concise live-demo sequence and sales pitch.

## Files

- `index.html` — page structure and content
- `styles.css` — visual design and responsive styling
- `script.js` — mobile navigation, WhatsApp enquiry form and swipe/lightbox gallery
- `PITCH-GUIDE.md` — presentation script and launch checklist
